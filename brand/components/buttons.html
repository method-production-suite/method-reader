The brad button is the page's one accent object besides the fasteners, so there is never more than one on screen. Disabled is held at 35% opacity, not hidden: it is waiting for hardware, and saying so is the point. The label uses --ink-on-brass, the accent's own ink: white on the light violet (5.83:1) and a deep violet on the dark one (7.92:1). Plain --ink would land at 2.75:1 in light mode and 1.9:1 in dark. The download is an <a> and the others are <button>, which is why the hover rules key off :not(:disabled) and not :enabled: an anchor never matches :enabled, so the real download link would have silently had no hover at all.
