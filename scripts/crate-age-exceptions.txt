# One "name version  # reason" per line, and the reason says its kind (SUITE-STANDARDS.md
# section 6); the script refuses a line that says neither:
#   - a security fix that cannot wait: the reason names its RUSTSEC id (RUSTSEC-YYYY-NNNN),
#     or its GitHub advisory id (GHSA-xxxx-xxxx-xxxx) while RustSec has none yet.
#     The release workflow (--release) honours these.
#   - a version already in the lock, waiting out its cooldown: the reason starts
#     "ages-out YYYY-MM-DD" (the day it turns 14 days old). A release ignores these, so it
#     cannot be tagged until that day.
#   - the owner's override for one named release: the reason starts "owner-approved
#     override", then who approved it, when, and "release vX.Y.Z". The release workflow
#     honours it for that tag only.
