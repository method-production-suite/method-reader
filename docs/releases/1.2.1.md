# Method Reader 1.2.1

**The Library tab works again on a Mac, and the report's table keeps its words whole.**

## Fixed

- **The Library tab showed an error instead of your scripts.** On a Mac, opening Method Reader from Finder or the Dock made the Library tab say "unsupported input type" and list nothing. It now lists every script you've converted. Your scripts were never lost: they were there all along and come back as soon as you update.
- **Names broken in the middle in a script's report.** The report's table could split a character's name, or a column heading, across two lines with room to spare beside it. Each one now stays on one line.
