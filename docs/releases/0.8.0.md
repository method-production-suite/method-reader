# Screepub 0.8.0

There is one Screepub for Mac now, and it updates itself.

## One app on your Mac

- **The older Mac app becomes the new one.** If you use it with its
  update check on, it installs the new app in its own place and opens
  it. Your books are untouched.
- **One download for every Mac.** Screepub-macOS.dmg works on Apple
  Silicon and Intel Macs running macOS 13 or later.

## If you used Screepub Desktop

- **It updates into the same app.** A few things happen once: it asks
  again whether to check for updates, macOS asks again to reach your
  reader the first time you copy to it, and Finder and the Dock still say
  Screepub Desktop until you rename it. If you had both apps, delete
  Screepub Desktop.

## Good to know

- Settings you tuned for a script in the older Mac app start from the
  defaults once. Your books are untouched.
- The new app has no Cancel during a conversion. Most scripts finish in
  seconds.
- Homebrew no longer installs the Mac app; download it instead. The
  command-line converter stays: `brew install --formula <owner>/tap/screepub`.
