# Screepub 0.11.1

Your Kindle file is ready almost instantly, with nothing else to install.

## Kindles over USB, faster

- **Screepub makes the Kindle file itself.** Copying to a Kindle over USB
  used to need Calibre, and waited on it to start every time. Now Screepub
  writes the file in a fraction of a second, with nothing installed. It is
  marked Beta.
- **Calibre is only for the best-layout file.** With Calibre, its KFX
  plugin and Kindle Previewer installed, modern Kindles still get KFX.
  Emailing to Kindle needs no tools at all.

## Good to know

- The new Kindle file reads back whole in two independent e-book readers,
  but hasn't been opened on a real Kindle yet. Tell us how it goes.
- Kindles from before 2012 can't read it. Use **Save a file**, then MOBI.
- Kindle files Calibre made for your books are rebuilt once, the next time
  you send each one.
