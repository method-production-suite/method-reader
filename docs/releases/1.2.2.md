# Method Reader 1.2.2

**On a Mac, updates now check more before they install, so the copy you have can only be replaced by a newer Method Reader from the same developer.**

## Safer updates

- **An update must carry Method Reader's own signature.** Before it replaces the app, Method Reader checks that the new version is signed by the same developer as the copy you have. If it is not, nothing is installed, your copy is left as it was, and the app tells you where to download the latest version.
- **No going back to an older version.** Once Method Reader has downloaded and checked a version, it will not accept an older one offered later.
- **Updates that ask for an administrator's password are set up by the system.** The new copy is checked before it goes in, and it belongs to the system rather than to your account, as an app in Applications should.

## Fixed

- **Some long file locations on Windows.** A location too long for the ordinary form, counted the way Windows counts it, now keeps its long form, so it still opens when you paste it. So does a file named after a port with a small raised number.

## Good to know

- Nothing changes in how scripts convert. Every script reads exactly as it did in 1.2.1, and the newer PDF reader underneath gives the same results.
