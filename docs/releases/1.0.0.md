# Method Reader 1.0.0

**Method Reader runs on Intel Macs again, and takes a .fountain as well as a PDF.** It also brings a script to try it on, clearer words in the window, and the fixes 0.13.1 was going to carry.

## More from every script

- **Intel Macs are back.** One download runs on Apple silicon and Intel, macOS 13 or later. An Intel Mac that stopped at 0.9.0 now offers to update.
- **Bring a .fountain, not only a PDF.** Drop one in or choose it, and it becomes a book.
- **More in the editable script.** Each scene heading in the .fdx now carries its page and its length in eighths. And there is a third kind beside Fountain and .fdx: .osf (beta), an open format for screenwriting apps that read it.
- **See what is on your reader (beta).** With a Kindle, Kobo or tolino plugged in, list its books and remove one. It asks first.

## Fixed

- **Several scripts to a Kindle in a row.** After one copy, the next script showed only Eject Kindle. Now each script has its own Copy button.
- **Side-by-side dialogue that runs long.** A long exchange in two columns came through as one jumbled paragraph. Both speeches now come through whole.

## Good to know

- If your copy is still called Screepub Desktop or Screepub, it renames itself Method Reader the first time 1.0.0 opens. A Dock icon or login item set up under the old name may need adding again.
- On Linux, Method Reader's own settings move once, from ~/.config to ~/.local/share.
- Method Reader is no longer on Homebrew. Install it from the downloads; it keeps itself up to date.
- Help, Report a Bug now writes an email you read and send yourself, so telling us something went wrong needs no GitHub account. Nothing from your script goes in it unless you add it.
