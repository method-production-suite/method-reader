# Method Reader 0.13.1

**Method Reader now comes with a script to try it on, and sending several scripts to a Kindle in a row works again.** The window's words are clearer, and a few rough edges on the Mac are gone.

## Easier to start

- **Field Station opens the first time.** An invented script comes with the app, ready to convert, so you can see what it does before you find a PDF of your own. Open it again any time from Help, Open Sample.
- **Clearer names in the window.** Preview is the book as it will look, Send to e-reader gets it onto your reader, and Get an editable script gives you the script back as Fountain or .fdx.
- **Other ways is easier to read.** Every way to send or save is one line with its button beside it, all in one column.

## Fixed

- **Several scripts to a Kindle in a row.** After one copy, the next script showed only Eject Kindle. Now each script has its own Copy button, with Eject beside it.
- **Side-by-side dialogue that runs long.** A long exchange in two columns came through as one jumbled paragraph. Both speeches now come through whole.
- **The right icon in the Dock.** While the app was open, the Dock showed a plain default icon instead of Method Reader's.
- **The right name in Applications.** If your copy is still called Screepub Desktop or Screepub, it renames itself Method Reader the first time 0.13.1 opens.

## Good to know

- A Dock icon or login item you set up under the old name may stop working after the rename. Add Method Reader again from Applications.
- A script with a long side-by-side exchange can convert a little differently than it did in 0.13.0. Convert it again to get the fixed book.
- On Linux, Method Reader's own settings move once, from ~/.config to ~/.local/share. Nothing else changes.
- Method Reader is no longer on Homebrew. Install it from the downloads; it keeps itself up to date.
