# Screepub 0.12.1

The command-line converter for Linux and Windows is back on the downloads page.

## For the command line

- **Linux and Windows downloads are back.** Screepub 0.12.0 shipped
  without its command-line converter for Linux and Windows, so those
  download links led nowhere. They work again. The apps were never
  affected.

## Good to know

- If you already have 0.12.0, nothing in the app changes.
